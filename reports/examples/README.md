# Relatórios de exemplo

Os relatórios reais gerados pelos scripts (`reports/*.txt`) não são versionados,
pois podem conter dados reais do ambiente onde o laboratório foi executado
(usuários, e-mails, hostnames).

Os arquivos `*.example.txt` nesta pasta mostram o formato de saída de cada
detector com dados fictícios, apenas para referência de quem for ler o projeto.
